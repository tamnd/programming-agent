How a page earns trust

  1. Plain words. The text uses short sentences and simple words. A reader who knows some code can follow it.
  2. Proof. A human proof shows why the algorithm is correct. A Lean proof lets a computer check it.
  3. Tests. Each implementation has native tests. The build runs them in a pinned toolchain.
  4. Honest badges. The build computes each badge from evidence. Nobody writes a badge by hand. Read about the badges.
