How a page earns trust

  1. Plain words. The text uses short sentences and simple words. A reader who knows some code can follow it.
  2. Code that runs. The build runs each example and records its output. A version claim, such as "since Python 3.10", comes from a probe that the build runs on each version.
  3. Sources. Each rule of a language cites the reference or the standard, at the version that it is about.
  4. Honest badges. The build computes each badge from evidence. Nobody writes a badge by hand. Read about the badges.
